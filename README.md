# Ultimatrix Prototype with ESP32
## Overview
The Ultimatrix Project is inspired by the iconic device featured in Ben 10 animated series. 
It recreates the aesthetic and interactive experience of the fictional watch by integrating microcontrollers, sound modules, and a custom 3D-printed case. 
Beyond its entertainment value, the project also has an educational purpose by incorporating features that support the teaching and practice of English vocabulary in a playful and engaging way. 
This dual approach positions the Ultimatrix as both a functional prototype for entertainment and a didactic tool for language learning.

## Materials and Components  

The development of the project required a combination of electronic, mechanical, and structural elements. The following table summarizes the main products and materials used:  

| Component                | Description |
|--------------------------|----------|
| **Microcontroller (ESP32)** | Central unit that controls inputs, outputs, and system logic |
| **Push Buttons**         | Allow user interaction, menu navigation, and activation |
| **OLED Display (SH1107)**   | Visual interface for menus, text, and alien selection |
| **Potentiometer**        | Dial construction and alien selection |
| **Speaker**        | Generate sound feedback and transformation effects |
| **Sound Module (DFPlayer Mini)**        | Generate sound feedback and transformation effects |
| **Powerbank** | Primary power source for the device |
| **3D-Printed Case**      | Structural housing that protects and enhances aesthetics |
| **Passive Components**   | Circuit stability, safety, and proper connections |

## Operation modes explained
The Ultimatrix includes several interactive modes that enhance both entertainment and educational experiences; these modes can be selected by the assigned button:  

- **MP3 Player:**  
  When powered on, the system displays a music player with the tracks stored on the micro SD card. With the buttons we can change the volume or pause and play the song;
   with the dial it's possible to select a desired song.  

- **Ultimatrix startup:**  
  The display shows the Omnitrix icon with a specific audio, telling the user that has achieved the master control.

- **Alien Selection Mode:**  
  Users navigate through aliens on the OLED display using the dial with the potentiometer, accompanied by sound effects that resemble the original watch interface.
  There are two modes dedicated to the alien selection, the first one is the classic series menu, and the other one has the Alien Force menu.

- **English Learning Mode:**  
  The last 4 modes are dedicated to English learning through easy phrases, vowels, numbers, and colors.
